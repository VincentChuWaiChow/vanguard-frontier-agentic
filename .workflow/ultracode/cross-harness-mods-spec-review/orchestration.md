# Orchestration

## Parent critical path

Read named skills and current spec/source; verify library claims; resolve intent;
edit all spec documents; verify integrated evidence.

## Packets

- `01-data-contract`: read-only schema, loader/store and failure modes.
- `02-ui-tasks`: read-only display path, tests and task dependencies.

## Delegation

Two discovery sidecars; no worker writes or recursive delegation.

## Agents

Requested: available `gpt-6.1-sol`, medium, fresh self-contained contexts.
Effective runtime isolation/model settings beyond tool evidence are unverified.

## Delegation limits

At most three cumulative runs including one review follow-up, two concurrent
workers, one bounded parent repair, 45-minute review budget before reassessment.

## Wait points

Only integrate after discovery results; do not wait while independent research
is available. No tests share mutable resources with workers.

## Fallback

If delegation is unavailable, perform bounded read-only passes locally.

## Verification order

Primary-source claims, local probes, requirements decisions, design/task
traceability, scoped checks, full repository gates, final audit.
