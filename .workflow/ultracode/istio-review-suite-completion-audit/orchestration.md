# Orchestration

## Parent critical path
Freeze the commit identity, prepare contracts, run verification, reproduce material findings, and issue the final audit.

## Packets
- `01-requirement-traceability`
- `02-security-routing-refutation`
- `03-packaging-release-audit`

## Delegation
One broad parallel read-only review wave; no agent may edit repository source.

## Agents
Three native review agents. Inventory found the usable built-in `explorer`; spawned agents inherit the active model and filesystem.

## Delegation limits
Three agents, one wave, exact bounded concerns, evidence-only handoffs.

## Wait points
Integrate only after all three reports arrive or a concrete blocker is reported.

## Fallback
The parent reproduces disputed or incomplete findings locally.

## Verification order
Identity and cleanliness, targeted suite checks, routing, packaging/export, full validation, final remote SHA comparison.
