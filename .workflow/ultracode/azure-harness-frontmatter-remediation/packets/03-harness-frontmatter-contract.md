# Packet 03 — harness frontmatter contract

Owner: read-only Haiku agent (`Explore`). Write scope: none.

## Question

What does each harness's official documentation say about `name` and
`description` in custom agent frontmatter, and what happens when they are
missing?

## Harnesses

Claude Code, Cursor, GitHub Copilot, Gemini CLI, Kiro IDE.

## Asks

For each: the URL fetched, the verbatim sentences on whether `name` and
`description` are required, optional or supported, any character rules for
`name`, the documented behaviour when either is missing, and any other
required key.

## Constraints

Primary sources only (vendor documentation). A harness whose documentation
does not address this is reported as "NOT DOCUMENTED" with the URLs tried,
never filled from memory.
