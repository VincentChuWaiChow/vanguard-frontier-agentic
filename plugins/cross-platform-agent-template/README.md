# Cross-Platform Agent Template

Cross-platform agent templates for adapting Vanguard Frontier Agentic workflows
to Codex, GitHub Copilot, Claude Code, Cursor, Gemini CLI, and Kiro without
hiding platform-specific capability differences.

## Installation

Install this directory as a local Codex plugin, or copy its templates into the
plugin structure expected by the target coding-agent platform.

## Usage

Use the plugin to:

- create a canonical cloud-security or zero-trust agent specification;
- generate only the adapters required by the selected platforms; and
- preserve least-privilege, approval, and evidence requirements while making
  platform-specific limitations explicit.

Review generated adapters before installation. Do not add credentials, tokens,
tenant identifiers, or customer data to agent definitions.
