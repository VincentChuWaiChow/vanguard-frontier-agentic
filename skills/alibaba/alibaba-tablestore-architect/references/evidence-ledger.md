# Evidence ledger — Alibaba Cloud Tablestore

Every material claim in
[tablestore-design-guide.md](tablestore-design-guide.md) cites one row below
as `[TS-Exx]`. `tests/validate-skill-references.py` fails the build if a
citation has no row, a row is never cited, or a source is not on an
allow-listed Alibaba Cloud documentation path.

Scope: **Tablestore Wide Column model** (formerly OTS). Not the TimeSeries or
Message models, not ApsaraDB for HBase or Lindorm. `VERIFIED` = the section
was retrieved on the retrieval date and supports the claim as worded; it is
documentation verification, not a behavioral test. Limits change: re-fetch
before relying on a number.
