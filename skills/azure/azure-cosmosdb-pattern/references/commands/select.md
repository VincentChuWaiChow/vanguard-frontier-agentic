   Ask only for missing API/workload information that blocks correctness.

   conditional reference, not permission to preload it. Selecting backup reads the
   overview first; choose one exact method before loading a method procedure.
3. Explain native capability, applicability, cost/risk, alternatives, constraints
   and what evidence is missing. Do not convert selection into feature enablement.
