# Backup dispatcher

Customer-owned recovery, not a native PITR snapshot. Select only `backup/migrator.md`
or `backup/sdk.md`; use the recovery-boundary guide for shared evidence. Require
source identity, consistency strategy, quiescence window, retention/key budget,
exact destination and separately approved read/export/storage writes. No automatic
backup, schedule or broad scan on load; request/plan is not execution proof.
