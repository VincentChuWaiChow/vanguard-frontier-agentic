# Select — scope only

Parse the requested feature IDs through `scripts/select_mode.py`; ask only if the
intended service/API blocks correctness. Return selected features/paths, assumptions
and unsupported requests. Load only returned guides, not linked children. Selection
lasts one request; it neither toggles OCI resources nor proves IAM or host routing.
For `vectors`, explain the reviewed absence of a verified NDCS native ANN interface
and offer a separately approved vector-service design, never a fictional command.
