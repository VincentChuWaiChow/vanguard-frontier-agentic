`tests/validate-skill-references.py` fails the build if a citation has no row,
a row is never cited, or a source is not on an allow-listed Oracle host.

Scope: **Oracle NoSQL Database Cloud Service (NDCS)** on OCI, "Latest Cloud
Release" documentation, non-hosted (standard) environment unless a row says
otherwise. Not Oracle Autonomous Database, not Oracle Database JSON, not
on-premises Oracle NoSQL Database.

Status meaning: `VERIFIED` = the quoted section was retrieved from the source
on the retrieval date and supports the claim as worded. `UNVERIFIED` = recorded
gap; do not present it as fact. `CONFLICT` = the source contradicts itself; do
not rely on either value. Documentation verification is not a behavioral test
against a live tenancy. Limits and prices are volatile: re-fetch before relying
on a number.
