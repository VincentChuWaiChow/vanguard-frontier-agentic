# Report project status

@confluence-document-authoring

Draft a Confluence project status report for [reporting period, cutoff, and timezone] using the [status report template](../assets/templates/project-status-report.md).

Separate completed outcomes with evidence from forecasts, planned work, blockers, risks, and decision requests. Compare milestones with the previous report where supplied. State the source and freshness of each material assessment.

Do not invent progress percentages or traffic-light ratings. Closed tickets do not prove deployment or customer availability. Keep missing measurements and stale evidence visible; use **Unknown** instead of guessing.

Return the complete dated snapshot, next actions, and specific decisions needed. Do not publish it.
