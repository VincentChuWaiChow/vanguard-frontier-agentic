# Evidence ledger — Atlassian Rovo MCP Server and Jira Cloud rate limits

`[ATL-Exx]`. `tests/validate-skill-references.py` fails the build if a citation has
no row, a row is never cited, or a source is not on an allow-listed Atlassian

Scope: the **Atlassian Rovo MCP Server** (cloud) and **Jira Cloud REST rate
limiting**. Not Data Center, not Forge, not third-party MCP servers.

supports the claim as worded; this is documentation verification, not a live
tenant test. `CONFLICT` = two official pages disagree; neither side may be encoded
as fact. Tool lists change (the supported-tools page was last updated 2026-11-02):
re-run `discover` in the actual session before relying on any tool name.
