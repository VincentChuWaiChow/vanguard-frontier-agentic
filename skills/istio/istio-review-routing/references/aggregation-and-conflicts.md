# Aggregation and disagreements

## ROUTE-04: preserve hard blockers and unknowns

Aggregate only required decisions within the same confirmed scope. A confirmed violation of a required condition blocks that decision. If no confirmed blocker exists but any required decision is unresolved, the result is needs-review. A favorable unrelated review cannot cancel a blocker. Missing intent is a material unknown, not an implicit permissive requirement.

Before combining two findings, align version, mode, target, proxy path, policy set, evidence time and desired behavior. Conflicting scopes are not factual disagreement. Actual unresolved contradictions remain visible with a next discriminating observation.

Never average severities or confidence scores into approval. Never treat an agent's self-report as a test result. Keep evidence references and unperformed tests in the aggregate output.

## Delegation boundary

Delegated work inherits the static-review ceiling. No delegate may obtain tools, network credentials or execution permission simply because the router assigned it a task. The host enforces capabilities independently from prompts.
