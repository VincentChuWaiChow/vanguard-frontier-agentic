# Evidence ledger — Cloud Bigtable

Every material claim in
[bigtable-design-guide.md](bigtable-design-guide.md) cites one row below as
`[BT-Exx]`. `tests/validate-skill-references.py` fails the build if a citation
has no row, a row is never cited, or a source is not an allow-listed Google
documentation host.

claim as worded; it is documentation verification, not a behavioral test.
