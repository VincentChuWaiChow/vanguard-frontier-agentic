# Official sources

The provider's own documentation is the authority for Scaleway Managed MongoDB® behaviour.
Third-party posts and model memory are leads, not evidence.

- [The evidence ledger](evidence-ledger.md) traces each material claim in
  [the operations reference](operations.md) to the provider page fetched on its
  retrieval date, with its status.
- Primary pages:
  - <https://www.scaleway.com/en/docs/managed-mongodb-databases/>

Re-fetch before relying on a limit, plan feature, metric name or permission: they
change. If no provider page settles a claim, label it unverified rather than
inferring it.
