# Official sources

AWS documentation is the authority for Amazon DocumentDB (with MongoDB compatibility) behaviour. Third-party posts and
model memory are leads, not evidence.

- [The evidence ledger](evidence-ledger.md) traces each material claim in
  [the operations reference](operations.md) to the AWS page fetched on its retrieval
  date, with its status.
- Primary pages:
  - <https://docs.aws.amazon.com/documentdb/latest/developerguide/what-is.html>
  - <https://docs.aws.amazon.com/documentdb/latest/developerguide/backup_restore.html>
  - <https://docs.aws.amazon.com/documentdb/latest/developerguide/global-clusters.html>

Re-fetch before relying on a limit, quota, metric name or IAM action: they change.
If no AWS page settles a claim, label it unverified rather than inferring it.
