[consistency-indexing-replication.md](consistency-indexing-replication.md)

the build if a citation has no row, a row is never cited, or a source is not
an allow-listed AWS documentation host.

Amazon DocumentDB or Amazon Keyspaces. `VERIFIED` = the section was retrieved
on the retrieval date and supports the claim as worded; it is documentation
